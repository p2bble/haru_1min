개인정보처리방침

하루 1분 (Haru 1Min) · 시행일: 2026년 6월 6일 · 개정일: 2026년 6월 10일

📋 요약
하루 1분은 모든 기록을 기기 내부에만 저장합니다.
단, 선택 기능인 AI 사진 분석을 사용할 때만 해당 사진이 분석 목적으로 Google 서버에 전송됩니다. 그 외 어떤 정보도 외부로 전송하거나 제3자에게 제공하지 않습니다.

1. 수집하는 정보

하루 1분은 아래의 정보만 수집하며, 모두 기기 내부 저장소에 보관됩니다.

  • 물 섭취 기록 — 사용자가 직접 입력한 날짜별 물 섭취량
  • 영양제 정보 — 사용자가 등록한 영양제 이름, 복용 시간, 사진
  • 복용 기록 — 날짜별 영양제 복용 여부
  • 앱 설정 — 하루 목표량, 컵 용량 등 사용자 설정값

위 정보는 앱의 기능 제공 목적으로만 사용되며, 아래 3절의 AI 사진 분석을 제외하고 외부로 전송되지 않습니다.

2. 수집하지 않는 정보

하루 1분은 다음 정보를 수집하지 않습니다.

  • 이름, 이메일, 전화번호 등 식별 가능한 개인정보
  • 위치 정보
  • 기기 고유 식별자
  • 광고 ID
  • 행동 분석 및 사용 통계

3. 카메라·저장소 권한 및 AI 사진 분석

영양제 사진 등록 기능을 위해 아래 권한을 요청합니다.

  • 카메라 — 영양제 사진을 직접 촬영할 때 사용
  • 사진 / 미디어 접근 — 갤러리에서 영양제 사진을 선택할 때 사용

촬영 또는 선택된 사진은 기기 내부 앱 전용 디렉터리에 저장됩니다.

AI 사진 분석(선택 기능): 사용자가 "AI로 자동 분석" 버튼을 누른 경우에만, 해당 영양제 사진이 분석을 위해 Google의 Gemini API(Firebase AI Logic)로 전송됩니다.

  • 전송 목적 — 영양제 이름·권장 복용 시간·복용 팁 자동 인식
  • 전송 시점 — 사용자가 분석 버튼을 직접 누른 때에만 전송되며, 자동 전송은 없습니다
  • 앱과 개발자는 전송된 사진을 별도 서버에 저장하지 않습니다
  • Google의 처리에는 Google 개인정보처리방침이 적용됩니다

AI 분석을 사용하지 않으면 사진은 외부로 전송되지 않습니다.

4. 데이터 저장 및 보관

  • 모든 데이터는 기기의 SQLite 로컬 데이터베이스에 저장됩니다.
  • 앱 삭제 시 모든 데이터가 함께 삭제됩니다.
  • 별도의 클라우드 백업 기능은 제공하지 않습니다.

5. 제3자 서비스

하루 1분은 광고 SDK, 소셜 로그인, 행동 분석 도구를 사용하지 않습니다.

AI 사진 분석 기능을 위해 아래 Google 서비스만 사용합니다.

  • Firebase AI Logic (Gemini API) — 영양제 사진 분석 (3절 참고)
  • Firebase App Check — 무단 API 접근 방지를 위한 앱 무결성 확인
AI 사진 분석을 제외한 모든 기능(기록·알림·통계·위젯)은 인터넷 연결 없이 사용할 수 있습니다.

6. 아동 개인정보 보호

하루 1분은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
