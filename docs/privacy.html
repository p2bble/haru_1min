개인정보처리방침

하루 1분 (Haru 1Min) · 시행일: 2026년 6월 6일

📋 요약
하루 1분은 모든 데이터를 기기 내부에만 저장합니다.
외부 서버로 개인정보를 전송하거나 제3자에게 제공하지 않습니다.

1. 수집하는 정보

하루 1분은 아래의 정보만 수집하며, 모두 기기 내부 저장소에 보관됩니다.

  • 물 섭취 기록 — 사용자가 직접 입력한 날짜별 물 섭취량
  • 영양제 정보 — 사용자가 등록한 영양제 이름, 복용 시간, 사진
  • 복용 기록 — 날짜별 영양제 복용 여부
  • 앱 설정 — 하루 목표량, 컵 용량 등 사용자 설정값

위 정보는 앱의 기능 제공 목적으로만 사용되며, 외부로 전송되지 않습니다.

2. 수집하지 않는 정보

하루 1분은 다음 정보를 수집하지 않습니다.

  • 이름, 이메일, 전화번호 등 식별 가능한 개인정보
  • 위치 정보
  • 기기 고유 식별자
  • 광고 ID
  • 행동 분석 및 사용 통계

3. 카메라 및 저장소 권한

영양제 사진 등록 기능을 위해 아래 권한을 요청합니다.

  • 카메라 — 영양제 사진을 직접 촬영할 때 사용
  • 사진 / 미디어 접근 — 갤러리에서 영양제 사진을 선택할 때 사용

촬영 또는 선택된 사진은 기기 내부 앱 전용 디렉터리에만 저장되며, 외부로 전송되지 않습니다.

4. 데이터 저장 및 보관

  • 모든 데이터는 기기의 SQLite 로컬 데이터베이스에 저장됩니다.
  • 앱 삭제 시 모든 데이터가 함께 삭제됩니다.
  • 별도의 클라우드 백업 기능은 제공하지 않습니다.

5. 제3자 서비스

하루 1분은 외부 분석 도구, 광고 SDK, 소셜 로그인 등 제3자 서비스를 사용하지 않습니다.

이 앱은 인터넷 연결 없이도 모든 기능을 정상적으로 사용할 수 있습니다.

6. 아동 개인정보 보호

하루 1분은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 개인정보처리방침 변경

본 방침이 변경될 경우 GitHub 저장소 및 앱 업데이트를 통해 사전 공지합니다.

변경 이력은 GitHub 저장소에서 확인하실 수 있습니다.
